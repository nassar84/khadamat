## 🔴 المرحلة 1: اختبار المصادقة (Authentication)

### TC-01: تسجيل الدخول الناجح
- **الرابط:** `/login`
- **الخطوات:**
  1. أدخل `Admin` في حقل اسم المستخدم
  2. أدخل `Admin@123` في حقل كلمة المرور
  3. اضغط زر "تسجيل الدخول"
- **النتيجة المتوقعة:** ✅ توجيه للصفحة الرئيسية، ظهور أيقونة المستخدم في الـ Navbar

### TC-02: تسجيل الدخول بكلمة مرور خاطئة
- **الخطوات:** أدخل `Admin` و `WrongPass123` ثم اضغط الزر
- **النتيجة المتوقعة:** ✅ ظهور رسالة خطأ "اسم المستخدم أو كلمة المرور غير صحيحة"

### TC-03: تسجيل الدخول بحقول فارغة
- **الخطوات:** اضغط زر "تسجيل الدخول" بدون إدخال أي بيانات
- **النتيجة المتوقعة:** ✅ ظهور رسائل Validation بالعربي

### TC-04: إنشاء حساب جديد
- **الرابط:** `/register`
- **الخطوات:**
  1. أدخل الاسم الكامل، اسم مستخدم فريد، بريد إلكتروني، كلمة مرور، رقم هاتف مصري
  2. اختر محافظة ومدينة
  3. اضغط "إنشاء حساب"
- **النتيجة المتوقعة:** ✅ إنشاء الحساب والتوجيه للرئيسية

### TC-05: نسيان كلمة المرور
- **الرابط:** `/forgot-password`
- **الخطوات:** أدخل `admin@khadamat.com` واضغط إرسال
- **النتيجة المتوقعة:** ✅ ظهور رسالة نجاح

### TC-06: الحماية من الوصول غير المصرح
- **الخطوات:** انتقل لـ `/admin` بدون تسجيل دخول
- **النتيجة المتوقعة:** ✅ توجيه لصفحة `/login` أو رسالة رفض الوصول

- **التحقق من:**

  - [x] ظهور بانر "كن مقدم خدمة"

### TC-08: التصنيفات الرئيسية

### TC-09: شريط البحث
- **الخطوات:** اكتب "سباك" في شريط البحث
- **النتيجة المتوقعة:** ✅ ظهور نتائج أو توجيه لصفحة البحث

## 🟡 المرحلة 3: الخدمات (Services)

### TC-10: صفحة جميع الخدمات
- **الرابط:** `/services`
- **التحقق من:**
  - [ ] تحميل قائمة الخدمات
  - [ ] عمل الفلترة بالتصنيف
  - [ ] عمل الفلترة بالمدينة
  - [ ] ظهور Pagination

### TC-11: تفاصيل الخدمة
- **الرابط:** `/service/{id}`
- **التحقق من:**
  - [ ] ظهور اسم الخدمة والوصف والصورة
  - [ ] ظهور معلومات المزود
  - [ ] ظهور التقييمات والتعليقات
  - [ ] زر "تواصل مع المزود" يعمل
  - [ ] زر "إضافة للمفضلة" يعمل (للمستخدمين المسجلين)
  - [ ] زر "اقتراح تعديل" يفتح نافذة التعديل

### TC-12: البحث في الخدمات
- **الرابط:** `/search`
- **الخطوات:** ابحث بكلمة "كهربائي"
- **النتيجة المتوقعة:** ✅ ظهور نتائج مرتبطة

### TC-13: الاستكشاف

- **التحقق من:** تحميل الصفحة وعرض الخدمات بطريقة Explore
