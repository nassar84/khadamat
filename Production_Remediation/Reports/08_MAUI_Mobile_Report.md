# تقرير 08: استقرار وتطوير تطبيق الموبايل .NET MAUI (MAUI Mobile Architecture Report)

أظهر التدقيق الشامل للحل وجود مشروعين يحملان اسم الموبايل:
1. `Khadamat.Mobile`: مشروع قديم غير مستخدم في خطوط النشر، ومبني بقالب افتراضي أولي.
2. **`Khadamat.MobileApp`:** **المشروع الفعلي والحقيقي والوحيد المستخدم لإنتاج ونشر تطبيقي Android و iOS**.
   - معرّف التطبيق الرسمي (ApplicationId): `com.nassar84.khadamawy`
   - اسم التطبيق المعروض (ApplicationTitle): **خدماوي**
   - رقم الإصدار: `2.9` (VersionCode: `21`)
   - إطار العمل المعتمد: `.NET 9.0 MAUI` (`net9.0-android`, `net9.0-ios`)

## 2. المشكلات التي تم حلها وتنفيذها في كود الموبايل

### أ. إصلاح خطأ تصغير واختفاء التطبيق عند الضغط على زر العودة (Back Button):
- **المشكلة السابقة:** عند قيام المستخدم باختيار فئة ثم فئة فرعية واستخدام زر الرجوع الفعلي في هاتف أندرويد، كان التطبيق يختفي ويتصغر بدلاً من الرجوع للصفحة السابقة.
- **الحل المنفذ:** تم اعتراض حدث زر الرجوع في `WebContainerPage.xaml.cs` عبر جسر JavaScript المزدوج (`evaluateJavaScriptAsync("history.back()")` و `Shell.Current.GoToAsync`) للعودة التدريجية المتسلسلة لصفحات التصنيفات والخدمات، مع حماية الخروج بنقرة مزدوجة وتنبيه Toast ("اضغط مرة أخرى للخروج من التطبيق").
- **تصحيح استدعاء إغلاق التطبيق:** تم تعديل السطر 956 إلى `Microsoft.Maui.Controls.Application.Current?.Quit()` لمنع تعارض مساحة الأسماء `Khadamat.Application` أثناء البناء.

### ب. توحيد ارتفاع كروت الخدمات المميزة في الصفحة الرئيسية:
- **المشكلة السابقة:** تفاوت وارتفاع غير منتظم لكروت الخدمات المميزة بناءً على طول نص الوصف المعروض.
- **الحل المنفذ:** تم تطبيق قواعد تنسيق CSS ومعالجة بنية الكروت لتكون بارتفاع موحد وثابت مع تثبيت شريط البيانات الوصفية (التقييمات، المفضلة، زر التواصل) في أسفل الكارت بشكل متناسق بصرياً مهما اختلف طول نص الوصف.

### ج. إزالة تبعية AutoMapper والقضاء على تحذير الثغرة:
- تم استئصال سطر الاعتماد من `Khadamat.MobileApp.csproj` لعدم وجود أي استخدام له في الموبايل، مما أدى إلى حذف تحذير الثغرة العالية `NU1903` وتسريع التجميع.

### د. تكامل فتح تطبيق واتساب الأصلي مباشرة:
- تم ضبط معالج الروابط في التطبيق لفتح تطبيق WhatsApp الرسمي عبر الـ Custom URI Schemes (`whatsapp://send?phone=...`) مباشرة بدلاً من الفتح العقيم داخل متصفح الويب الداخلي.

## 3. المعمارية البرمجية والمكونات الرئيسية

- **الواجهة الهجينة المحسنة (Hybrid WebContainer):** يستخدم التطبيق `BlazorHybrid / WebView` مخصصاً وعالي الأداء يربط واجهة العرض الرشيقة مع ميزات العتاد الأصلية للموبايل (الكاميرا، التخزين، الإشعارات، الاتصال الهاتفي، تطبيق الرسائل).
- **التخزين المحلي غير المتصل (Offline SQLite):** يعتمد التطبيق على مكتبة `SQLitePCLRaw.bundle_green 2.1.10` لتخزين التفضيلات وبيانات الجلسة محلياً، مع محاذاة صفحات الذاكرة 16 KB بالكامل.
- **إدارة دورة حياة الذاكرة والموارد:** تم ضبط `LocalDataService` و `ShellViewModel` لإلغاء الاشتراكات والمهام المؤقتة فور مغادرة الصفحات لمنع تسريبات الذاكرة (Memory Leaks).
