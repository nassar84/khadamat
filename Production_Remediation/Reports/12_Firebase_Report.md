# تقرير 12: مراجعة وتأمين خدمة الإشعارات Firebase Cloud Messaging (Firebase Report)

## 1. المشكلة الأصلية والهدف المعماري

تعد الإشعارات الفورية (Push Notifications) عبر **Firebase Cloud Messaging (FCM)** ركيزة أساسية لتنبيه المستخدمين ومقدمي الخدمات بتحديثات الطلبات، الرسائل، والموافقات الإدارية.
الأهداف الأساسية للتدقيق والتحسين:
1. تأمين بيانات اعتماد Firebase Admin SDK وتجنب تضمين المفاتيح الخاصة (Private Keys) في الكود المصدري أو مستودع Git.
2. إدارة دورة حياة توكنات الأجهزة (Device Tokens Lifecycle): تسجيل التوكن، تحديثه عند التجديد، وحذف التوكنات المنتهية أو غير الصالحة.
3. معالجة حالات استقبال الإشعارات في الموبايل عبر الحالات الثلاث: المقدمة (Foreground)، الخلفية (Background)، والتطبيق المغلق (Terminated).
4. إنشاء قنوات إشعارات Android الرسمية (Notification Channels) وفق متطلبات Android 8.0+.

---

## 2. المعمارية البرمجية المنفذة لإدارة الإشعارات

### أ. حماية أسرار Firebase Admin SDK:
- يتم تهيئة الـ Firebase Admin في `src/Khadamat.Infrastructure/Services/FirebaseNotificationService.cs` باستخدام متغير البيئة السحابي أو المسار الآمن المحدد في ملفات الإعدادات المعزولة.
- تم التأكد من إدراج كافة ملفات `*firebase*.json` و `google-services.json` داخل ملف `.gitignore` لمنع رفع أي بيانات اعتماد حساسة إلى مستودع الكود.

### ب. إدارة دورة حياة توكنات الأجهزة (`DeviceToken`):
- عند تسجيل دخول المستخدم في تطبيق الموبايل، يرسل التطبيق توكن الـ FCM إلى نقطة النهاية `POST /v1/notifications/register-token`.
- يقوم الخادم بحفظ أو تحديث التوكن المرتبط بالمستخدم في جدول `DeviceTokens`.
- عند إرسال إشعار وورود استجابة `FirebaseMessagingException` تفيد بأن التوكن غير صالح أو ملغى (`messaging/registration-token-not-registered`)، يقوم النظام بحذف التوكن تلقائياً من قاعدة البيانات لمنع تكرار محاولات الإرسال الفاشلة وتخفيف الحمل على الشبكة.

### ج. إعداد قنوات الإشعارات في أندرويد (Notification Channels):
- تم ضبط قنوات الإشعارات الافتراضية داخل إعدادات تطبيق الموبايل:
  - **`default_notification_channel`:** ذات أهمية عالية (`Importance.High`)، مع دعم الاهتزاز والصوت الافتراضي لعرض التنبيهات المنبثقة (Heads-up Notifications) فور وصول رسائل جديدة.
- تم ضبط أيقونة الإشعار المخصصة المتوافقة مع معايير أندرويد للشفافية وتصميم Material Design.
